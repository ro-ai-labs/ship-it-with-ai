(12:52) Can I really write code with AI? Yes. If you already read code and test changes, bring those skills to the agent’s work. If you are learning, practise them on a small task. Brief: explain the problem, who it is for, and what done looks like. “Make me an Excel clone” is a starting point. “Keep it in this browser, save my changes, and make this calculation work” gives you something to check. Read: inspect what comes back, including the choices the agent made. If it says “saved locally”, ask whether that means it survives a refresh or appears on another computer. [Pause 3 seconds.] Test: write the expected behaviour before building. Use tests to record that agreement, and read them as well as the code. Try examples whose answers you know, including an empty input. Judge: decide whether the result is ready, the task needs to be smaller, or you need another person’s review.
